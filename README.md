# Student Management System Website Prototype

This repository is now a simple browser-based website prototype. It no longer depends on database credentials or private setup files, so anyone can download the repo and open the page on any machine with a browser.

## What is included

- Student, Teacher, and Management sections
- A clean dashboard layout for presentation
- Static HTML and CSS for easy sharing
- An optional Java launcher that opens the page locally

## How to run locally

1. Clone or download the repository.
2. Open `index.html` in any browser.
3. Optional: run `project/src/App.java` if you want the page to open automatically from Java.

## How to publish as a website

1. Push this repository to GitHub.
2. Open the repository settings.
3. Go to the Pages section.
4. Set the source to the main branch and the root folder.
5. Save the settings and wait for GitHub Pages to generate the site link.
6. Share the GitHub Pages URL as your prototype website link.

## Project files

- `index.html` - main website page
- `styles.css` - visual styling
- `project/src/App.java` - optional local launcher
